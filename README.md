## 📖 About

A Python script that automates downloading an entire YouTube playlist
using **y2mate** through **Selenium**. Built to practice browser
automation and CLI scripting.

## ✨ Features

- Reads a playlist URL and walks through every video
- Browser automation with **Selenium**
- Headless-ish flow for an unattended run
